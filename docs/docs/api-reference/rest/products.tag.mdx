SKU-level product classification (Hazmat/Fragile/TemperatureSensitive/ Oversized/HighValue). Owned by product-master since ADR 0034: this service keeps a read-only local copy, fed by product-master's `ProductClassified` events, that StowStock reads to enforce hazmat/temperature placement (ADR 0009) and same-bin DOT segregation (ADR 0010). The write endpoint answers 410 and the read endpoint is deprecated.
