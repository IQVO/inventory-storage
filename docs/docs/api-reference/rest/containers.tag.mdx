Sealed cases with an identity (ADR 0045, 0046). A Container is a case licence plate (LPN, the carton SSCC) created from inbound-receiving's `ReceiptCartonReceived`; it is stowed into a case bin, and broken (`BreakCase`) into loose eaches. The ledger stays in eaches. Quantity is booked once, by `ReceiptLineReceived`, never by a container.
