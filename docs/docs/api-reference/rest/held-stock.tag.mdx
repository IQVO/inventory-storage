Stock held out of usable quantity (ADR 0052): the Damaged lines of an inbound receipt, which are booked as HELD units instead of being dropped. A held unit has no usable quantity and can never be reserved; a disposition (RELEASE, RETURN_TO_VENDOR, SCRAP, REWORK) settles it.
